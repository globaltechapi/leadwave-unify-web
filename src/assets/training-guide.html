Introduction

Welcome to LeadWave, a powerful WhatsApp automation desktop application built with Electron.js and the Baileys library. This comprehensive guide will walk you through the installation process and teach you how to use all the features of LeadWave to automate your WhatsApp communications.

Multi-Device Support

Connect and manage multiple WhatsApp accounts simultaneously from a single interface.

Group Management

Create, manage, and automate interactions with WhatsApp groups and communities.

Advanced Messaging

Send text, media, interactive messages, polls, and more with powerful templates.

Automation Features

Auto-reply, chatbots, and call responders to handle communications automatically.

Analytics & Reporting

Track message statistics, campaign performance, and device activity.

AI Integration

Leverage OpenAI and Google Gemini for intelligent, context-aware conversations.

Installation Guide

1

System Requirements

Before installing LeadWave, ensure your system meets the following requirements:

  • OS: Windows 10+
  • Processor: Intel Core i3 or equivalent
  • Memory: 4 GB RAM minimum (8 GB recommended)
  • Storage: 500 MB available space
  • Internet: Required for activation and connectivity
2

Downloading the Installer

Download the LeadWave installer from the official source or your licensed provider.

Pro Tip

Always download from official sources to ensure security and authenticity.

3

Installation Process

  1. Locate the downloaded installer file
  2. Double-click to begin installation
  3. Accept the license agreement
  4. Choose installation directory
  5. Click "Install" and wait for completion
  6. Click "Finish" to complete
4

First Launch

After installation, launch LeadWave and:

  • Allow through firewall if prompted
  • Grant necessary permissions
  • Complete initial registration

Note

LeadWave requires a valid license to operate. If you don't have a license, you may be able to use a trial version if available.

Devices Module

The Devices module is where you manage your WhatsApp connections. You can connect multiple WhatsApp accounts to LeadWave simultaneously.

1

Adding a New Device

  1. Click on "Devices" in sidebar navigation
  2. Click the "Add Device" button
  3. Enter a descriptive name for your device/session
  4. Choose between QR Code or Pairing Code authentication
2

QR Code Connection

  1. After creating a device, click "Show QR Code"
  2. Open WhatsApp on your phone
  3. Go to Settings > Linked Devices > Link a Device
  4. Scan the QR code displayed in LeadWave
  5. Wait for the connection to establish
3

Pairing Code Connection

  1. Select "Use Pairing Code Instead" when adding a device
  2. Enter your phone number with country code
  3. Click "Get Code" to generate a pairing code
  4. On your phone, go to Settings > Linked Devices > Link with Phone Number
  5. Enter the pairing code when prompted
4

Managing Connected Devices

Once connected, you can perform various actions:

  • Disconnect: Temporarily disconnect without losing session data
  • Reconnect: Reconnect a disconnected session
  • Delete: Permanently remove a device and all associated data

Pro Tip

Connected devices will automatically reconnect when you restart LeadWave, maintaining your session.

Manage Groups Module

The Manage Groups module is a comprehensive WhatsApp group management system that allows you to create and manage groups with advanced features.

1

Accessing the Module

  1. Click on "Manage Group" in the sidebar navigation
  2. Select a WhatsApp session from the dropdown
  3. Click "Refresh Groups" to load your existing groups
2

Creating a New Group

  1. Click the "Create Group" button
  2. Enter a group name (required)
  3. Optionally add a group description
  4. Enter participant phone numbers (one per line, with country codes)
  5. Click "Create Group"
3

Managing Group Participants

For any existing group, you can manage participants by clicking the user icon:

  • Add Participants: Add new members to the group
  • Remove Participants: Remove members from the group
  • Promote to Admin: Make members group administrators
  • Demote from Admin: Remove admin privileges from members
4

Sending Group Messages

  1. Click the message icon next to any group
  2. Choose mention options:
    • No mentions
    • Mention all (@everyone)
    • Mention admins only
  3. Type your message
  4. Click "Send Message"
5

Bulk Group Operations

You can perform actions on multiple groups simultaneously:

  1. Select multiple groups using checkboxes
  2. Click "Bulk Actions" button
  3. Choose an action:
    • Update Description
    • Update Group Name
    • Update Group Photo
  4. Enter the new value or upload a new photo
  5. Click "Apply to All"
6

Group Settings

Manage group settings by clicking the settings icon:

  • Announcement Mode: Only admins can send messages
  • Disappearing Messages: Messages disappear after 7 days

Important

WhatsApp only allows adding known contacts to groups directly. Unknown numbers will be rejected. Add numbers to your WhatsApp contacts first or manually add them to the group once via the WhatsApp app.

Pro Tip

Use the search function to quickly find specific groups by name or ID.

Templates Module

The Templates module allows you to create and manage message templates for various WhatsApp message types.

1

Supported Template Types

  • Text Message: Simple text with variable support
  • Message + Image: Text with image attachment
  • Message + Document: Text with document attachment
  • Message + Contact: Text with contact card
  • Message + Poll: Interactive poll with multiple options
  • Message + Buttons: Interactive message with clickable buttons
  • Message + List: Interactive message with selectable list
  • Message + Location: Text with location coordinates
  • Message + Video: Text with video attachment
  • Message + Audio: Text with audio attachment
2

Creating a Template

  1. Click on "Templates" in the sidebar navigation
  2. Click "Add Template"
  3. Select a template type
  4. Enter a template name and category
  5. Fill in the content and any additional fields specific to the template type
  6. Use {{variable}} syntax for dynamic content
  7. Click "Save"
3

Using Templates

  1. In any template card, click "Send"
  2. Select a WhatsApp session
  3. Enter the recipient's phone number
  4. Fill in any template variables
  5. Preview the message
  6. Click "Send Message"

Bulk Messages Module

Send messages to multiple contacts or groups simultaneously with the Bulk Messages module.

1

Creating a Bulk Campaign

  1. Click on "Bulk Messages" in the sidebar navigation
  2. Click "Create Campaign"

Auto Reply Module

Set up automated responses to incoming WhatsApp messages based on keywords or message content.

1

Creating an Auto Reply Rule

  1. Click on "Auto Reply" in the sidebar navigation
  2. Click "Create Rule"
  3. Enter a rule name and description
  4. Select WhatsApp sessions the rule applies to
  5. Set trigger conditions (keywords, message content, etc.)
  6. Define the response (text, template, or media)
  7. Set cooldown period to prevent spam
  8. Activate the rule
2

Managing Rules

You can edit, duplicate, or delete existing rules as needed. Use the search and filter options to find specific rules.

Chatbot Module

Create sophisticated automated conversation flows with the Chatbot module.

1

Creating a Chatbot Flow

  1. Click on "Chatbot Flows" in the sidebar navigation
  2. Click "Create Chatbot"
  3. Enter chatbot name and description
  4. Select WhatsApp sessions
  5. Design your conversation flow using the visual editor
  6. Add nodes for different conversation paths
  7. Set triggers to start the chatbot
  8. Activate the chatbot
2

Chatbot Node Types

  • Message Node: Send a message to the user
  • Question Node: Ask the user a question and wait for a response
  • Condition Node: Branch the conversation based on user responses
  • Action Node: Perform specific actions (save data, send to webhook, etc.)
  • End Node: End the conversation

Troubleshooting

1

Common Issues and Solutions

Device Connection Problems

  • Issue: QR code won't scan
    Solution: Ensure you're scanning within 30 seconds and have a stable internet connection
  • Issue: Device shows as disconnected
    Solution: Click "Reconnect" or restart the application
  • Issue: Pairing code not working
    Solution: Verify phone number format and ensure WhatsApp is updated

Message Sending Issues

  • Issue: Messages failing to send
    Solution: Check if the recipient's number is correct and if your device is connected
  • Issue: Delayed message delivery
    Solution: WhatsApp may rate-limit messages; try sending fewer messages

Template Problems

  • Issue: Variables not replacing
    Solution: Ensure variable names match exactly and are enclosed in {{ }}
  • Issue: Media not attaching
    Solution: Check file formats and sizes; WhatsApp has limitations on media types
2

Getting Support

If you encounter issues not covered in this guide:

  • Check the application logs for error messages
  • Restart the application
  • Ensure you're using the latest version
  • Contact support with detailed information about the issue
